## 約束 4：書き換えた試験の例（`tests/test_intake.py`。N-24 のコミット `bf00c02`）

手本は tsunagu-net の `tests/test_intake.py`。N-11（`5895218`）で写し、N-24 で、提供元の機関 ID を案に書かせない形（台帳 G-56）に合わせて書き換えた。

| # | tsunagu-net の元の例 | N-11 で写した形 | N-24 で書き換えた後 | 止める・通す |
|---|---|---|---|---|
| 1 | 案を作る `_proposal`：`"providerOrgId": PROVIDER` を案に入れる（42 行） | 同じ（`householdId` を `clientId` にした） | 案には `"providerName": "デイサービス事業所"`（原文の名前）を入れる。機関 ID は `_check` が `provider_org_id=PROVIDER` で別に渡す | `_proposal` を使う例はどれも、元と同じ判定のまま（通す例は通し、止める例は止める）。自分の記録に提供元を書く例（`documentKind="OwnCaseRecord"`）も、元は `providerOrgId`、今は `providerName` が残って **止める**（同じ） |
| 2 | `_check(_proposal(providerOrgId=None))` 書面なのに提供元が無い（149 行） | 同じ | `_check(_proposal(), provider_org_id=None)` 書面なのに職員が提供元を選んでいない | 元：**止める** → 後：**止める**（同じ）。別に `_check(_proposal(providerName=None))`（原文の提供元の名前が無い）を**止める**例として足した |
| 3 | （tsunagu-net には無い） | `_check(_proposal(providerOrgId="CLI-…"))` 提供元に機関でない ID | `_check(_proposal(), provider_org_id="CLI-…")` | 元：**止める** → 後：**止める**（同じ）。N-11 で nest-support が足した例で、tsunagu-net の例ではない |

台帳 G-56 には「写した試験のうち 3 か所」と書いたが、3 つめは tsunagu-net から写した例ではなかった。tsunagu-net から写した例で書き換えたのは 1 と 2 の 2 か所。
