# 声の記録のガイド

- 版：2026-11-06（計画 N-29 で書き直した。前の版の「Gemini で構造化して登録」「感情のタグ」はやめた）
- 対象：グループホーム・事業所の現場の職員

---

## 今の作り（何が起きるか）

1. 職員が録音する（スマホ・IC レコーダー）
2. 文字起こしは**既定で止めている**（Google の Gemini に送るため。`docs/external-api.md` NEXT-03）。使うのは、事業所が契約を確かめて設定したときだけ。止めている間は、聞きながら文に起こす
3. 起こした文を `narrative-extractor` に渡すと、Claude が**書き込みの案**（JSON）を作る。DB には書かない
4. 職員が案を確かめ、ゲートを通して登録する。AI が作ったものは「未確定」で入り、職員が一つずつ承認する

録音そのもの・文字起こしの全文は DB に入れません。DB に入るのは、事実ごとの言い換えと原文からの引用、原文の指紋（ハッシュ）だけです。

---

## 話し方

| 項目 | 話す内容 | 例（架空） |
|---|---|---|
| いつ | 日付・時間帯 | 「今日の昼食のとき」 |
| 誰のこと | 仮名（`C-…`）か「本人」 | 「C-ZZZZZZ さん」 |
| 何が起きたか | 見たこと・聞いたこと | 「隣の部屋の工事の音で、大きな声を出した」 |
| どうしたか | 職員の対応 | 「静かな部屋に移った」 |
| どうなったか | 結果 | 「10 分ほどで落ち着いた」 |
| 誰から聞いたか | 自分で見たか、聞いた話か | 「母の話では」「本人が言うには」 |

- **見たことと、聞いた話と、自分の推測を分けて話す。** 案の確度（見た・聞いた・本人の話・推測）がそこから決まる
- ほかの人は役割の名前で言う（母・主治医・担当の相談員・ほかの利用者）。ほかの利用者の名前は出さない
- 本人の気持ちは、見えた様子で言う（「声が大きくなった」「笑っていた」）。分類のタグは付けない

## 音声ファイルの置き場所と保存の期間

正典 §4.2 のとおり、音声ファイルの置き場所と保存の期間は DB に持たず、この文書で決めます。

- **置き場所**：事業所が決めた、鍵のかかる保存の場所（暗号化した端末か、アクセスを限った共有のフォルダ）。**DB にもリポジトリにも置かない。** メール・個人の LINE・個人のクラウドに送らない
- field-ui の録音の画面（`/voice`）は、受け取った音声を一時のファイルにし、文字起こしの後にすぐ消す。サーバには残らない
- ファイルの名前に本人の名前を入れない（仮名と日付にする）
- **保存の期間**：【未決】（事業所の記録の保存の規程に合わせて、段階 F の止まる点で決める）。仮の既定（2026-11-06 河原さん）：文字起こしの記録（`Record`）が承認されたら消す。遅くとも 30 日
- 期間を過ぎたファイルを消すときは、誰がいつ消したかを事業所の記録に残す

## 録音のときの注意

- 本人の前で録音しない
- 静かな場所で、その日のうちに話す
- 録音のファイルは、上の置き場所の外に出さない
