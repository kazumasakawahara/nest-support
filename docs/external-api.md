# 外部 API の一覧（何を送るか）

- 状態：v0.1（2026-11-05。N-00。方針は ADR-001 D10・D11 で河原さんが承認）
- 根拠：ADR-001 D10（埋め込みをやめる）・D11（外に送るものは既定で送らない）、約束 v1「外部 API に何を送るか（それぞれが文書に書く）」
- **この一覧に無い送信はしない。** 行を足すか、「既定」を変えるときは、河原さんが決め、その人と日付を書く
- 「外部」とは、使う人の Mac の外にある、他者が運営するサービスのこと
- 「使う人」とは、nest-support を使う相談支援専門員・事業所のこと

## 0. 前提

- **Claude に読ませた内容は、Anthropic の API に送られる。** 貼り付けた語り、添付のファイル、MCP の照会の結果のどれも同じ。「Mac で動かせば外に出ない」わけではない
- nest-support の DB（個人の側）の中身は、要配慮個人情報（個人情報の保護に関する法律 第2条第3項）を中心にする。既定ではどこにも送らない
- 外部 API の鍵（`GEMINI_API_KEY` など）が設定されていることを、「送ってよい」の印にしない。鍵は他のプロジェクトのために設定されていることがある（ADR-001 D11-1）
- **契約の確認の記録**：実データを送る行は、使う人が送り先との契約を確かめ、次の項目を記録したときだけ使える。記録はリポジトリの外に置く（置き場所と形は N-02 で決める）
  - 確かめた人と日付
  - 送り先と契約の名前・版（例：どのプランの利用規約か）
  - 入力を学習に使うか、保存の期間
  - 外国にある第三者への提供（同法 第28条）として扱うか、委託（同法 第27条第5項第1号）として扱えるか、の整理
  - 要配慮個人情報を送ること
- 条番号は e-Gov で照合済み（2026-11-05）。委託と提供の区別についての個人情報保護委員会の Q&A は照合していない【未照合】

| NEXT-04 | Gemini（同上） | 手書きの記録の OCR（`file_readers` の予備の読み取り、`ocr_with_gemini`） | スキャンの画像 | ほかのすべて | **止める**（NEXT-03 と同じ条件） | 河原さん 2026-11-05（ADR-001 D11-1） |

## 5. 機械の歯止め（実装で入れる）

- 送り先の一覧（この文書の NEXT 行のホスト）をコードに持つ。一覧に無い送り先には送らず、失敗させる（N-02）
- Gemini と LINE は、機能ごとの明示の設定と契約の確認の記録がそろわなければ送らない。鍵の有無は見ない（N-02・N-03）
- MCP の読み取りの包みは、既定で実名・かな・電話・住所・生年月日を返さない（N-22）
