# 訪問前ブリーフィング (Visit Preparation Workflow)

**マニフェスト価値:** 安全 (Safety), 継続性 (Continuity)
**使用場面:** 訪問・同行支援の前日〜当日

> 2026-11-06（E-3。台帳 G-71）：DB を読む箇所を今の構成（読み取りの包み・仮名・スキルの照会）に合わせた。照会の文はスキルの側に一つだけ持つ。

---

## 概要

訪問支援や同行支援の前に、対象の本人（仮名 `displayCode`）の重要情報を簡潔に確認するワークフロー。手順は `visit-prep` スキルが持つ。
「知らなかったために起きる事故」を防ぐことが最大の目的。

---

## 実行手順

### 1. 訪問前ブリーフィングの取得

→ `neo4j-support-db` スキルの照会 2〜6（禁忌・推奨ケア・特性・支える人・関わる機関）を `nest-personal` の `read_personal_cypher` で流す。

### 2. 最近の支援記録の確認

直近の支援状況を把握する。
→ `neo4j-support-db` スキルの照会 10（支援記録）を流す。

確認ポイント：
- 前回の訪問で何があったか
- 最近の体調・気分の変化
- 前回の申し送り事項

### 3. 効果的な対応パターンの確認

→ `neo4j-support-db` スキルの照会 11（効果のあったケア）を流す。

特に訪問の目的に関連するパターンを抽出する。例：
- 同行支援（外出）→ 外出時に効果的だった対応
- 食事支援 → 食事に関する配慮事項
- 服薬確認 → 服薬に関するこだわり

### 4. 更新期限の確認（訪問時に手続きが必要な場合）

→ `neo4j-support-db` スキルの照会 7（手帳・受給者証）を流す。

手帳や受給者証の更新が近い場合、訪問時に書類を準備する。

### 5. ブリーフィング出力

以下の形式で簡潔にまとめる。

```markdown
## 📋 訪問前ブリーフィング
**対象:** C-……
**訪問日:** [日付]
**訪問目的:** [目的]

### ⚠️ 絶対に避けること
- [禁忌事項リスト]

### ✅ 効果的な関わり方
- [推奨ケアリスト]

### 📞 緊急時の連絡先
連絡先は Claude から出せない。手元の緊急連絡カードと SOS の画面で確かめる。キーパーソンは人の ID と続柄で示す。

### 📝 前回からの申し送り
- [直近の支援記録の要点]

### 📅 確認すべき期限
- [該当する更新期限]
```

---

## 同行支援（外出）の場合の追加確認

外出先でのリスクを事前に把握する。

- **パニックの引き金:** 大きな音、人混み、特定の場所等
- **落ち着ける方法:** 音楽、静かな場所への移動等
- **持ち物チェック:** 薬、緊急連絡先カード、好きなアイテム
- **近隣の医療機関:** 外出先の最寄り病院

---

## 実例

```
入力（架空）: 「C-ZZZZZZ さんの同行支援でデパートに行くことになりました。気を付けることを教えて下さい。」

実行:
1. neo4j-support-db 照会 2・3 → 禁忌・推奨ケア（nest-personal の read_personal_cypher）
2. neo4j-support-db 照会 10 → 最近の支援記録（5 件）
3. neo4j-support-db 照会 11 → 外出の場面で効果のあったケア
4. ブリーフィング形式で出力
```
